# Anne Anita Beaula P — Portfolio

This repo contains a single-page portfolio website.

## Files
- `index.html` — the full portfolio (self-contained; resume is embedded, so the download button works even without the PDF file present)
- `Anne_Anita_Beaula_Resume.pdf` — a standalone copy of the resume, included for reference / direct linking if needed

## How to publish with GitHub Pages
1. Create a new GitHub repository (e.g. `portfolio`).
2. Upload these files to the repo (or `git push` them).
3. Go to the repo's **Settings → Pages**.
4. Under "Build and deployment", set **Source** to `Deploy from a branch`, choose the `main` branch and `/ (root)` folder, then Save.
5. GitHub will give you a live URL, usually `https://<your-username>.github.io/<repo-name>/`, within a minute or two.

## To customize later
- Update the LinkedIn/GitHub links in the Contact section of `index.html` (currently placeholders).
- Replace `Anne_Anita_Beaula_Resume.pdf` with an updated resume if needed — remember the download button uses the version embedded inside `index.html`, so re-embed if you update the resume (or ask for a refreshed export).
